# Tailscale 提供的能力（以及 DropSluice 用到了哪几条）

> 这篇单独讲 **Tailscale 本身**给了什么。它是「虚拟内网」，不是公网通道：**两端都得装并登录同一个 Tailnet**，否则地址根本到不了。
> 要「对方不用装任何东西」 → 用 [公网地址（Cloudflare 隧道）](remote-public.md)。

## 一、Tailscale 的核心能力

| 能力 | 它到底意味着什么 | DropSluice 用到了吗 |
| --- | --- | --- |
| **NAT 穿透后仍能互连** | 两端各自在路由器后面也能直连，不用公网 IP、不用端口映射、不用改路由器 | ✅ 用到了：`100.x` 地址就是靠这条 |
| **固定地址（`100.64.0.0/10`）** | 每台设备一个稳定的 CGNAT 地址，重启路由器也不变 | ✅ 用到了：面板/终端/浮层显示的那条 `http://100.x:18888/` |
| **MagicDNS 名字** | `机器名.tailXXXX.ts.net` 这种名字，比 IP 好记 | ✅ 用到了：面板卡片里显示 `dnsName` |
| **WireGuard 端到端加密** | 路径上的字节都加密，中继（DERP）也看不到明文 | ✅ 用到了（透明地）：传输本身不需要再做 TLS |
| **默认不对公网开放** | 地址在公网不可路由，别人扫不到、不知道存在 | ✅ 这就是选它的理由 |
| **设备在线状态** | `tailscale status` 能看到谁在线、上次活跃多久 | ✅ 用到了：诊断「手机连不上」时先看它是否 offline |
| **ACL / 设备授权** | 可以在管理后台限制谁能访问哪些端口 | ⚠️ 未做：DropSluice 没读 ACL，默认同一 tailnet 内互通 |
| **子网路由 / Exit Node** | 把整个局域网或全部流量导进 tailnet | ❌ 没用：本服务只暴露 18888 一个端口 |
| **给别人分享单个节点** | 不加入同一 tailnet 也能访问某台设备（share） | ❌ 没做：DropSluice 的配对机制是另一条独立通道 |
| **多平台客户端** | Windows / macOS / Linux / iOS / Android / 路由器 | ✅ 手机端就是靠它 |

## 二、它**不**提供什么（容易误解的地方）

- **不是公网可达**：没装 Tailscale 的手机连 `100.x` 地址是**完全到不了**的，不是「慢一点」。
- **不是 CDN / 不加速公网**：直连时走你家宽带的上行；打洞失败走 DERP 中继，反而更慢。
- **不能替代配对**：进了 tailnet 只是「网络通了」，DropSluice 仍然要配对码 + Cookie 才给看文件。
- **不管域名**：`MagicDNS` 只在 tailnet 内部解析，把这个域名贴到公网没用。

## 三、在 DropSluice 里的具体落点

- `lib/net.mjs`：`isTailnetIp(ip)` 判 `100.64.0.0/10`；`tailscaleInfo()` 读 `tailscale status --json`，取 `Self.TailscaleIPs[0]` 与 `Self.DNSName`（缓存 30 秒）。
- `lib/app.mjs`：`/api/admin/state` 的 `tailnet: { up, ip, dnsName, url, pairUrl }`；`/qr.svg?target=remote` 画「尾网地址 + 当前配对码」；设备列表里尾网来源标成 `同一 Tailnet · 用流量也能连`，且**不回查 IP 归属地**。
- 面板 / 终端 / DSH 浮层：三处都会显示这条地址（有 Tailscale 才出现）。
- 防火墙：需要单独放行 `100.64.0.0/255.192.0.0` 这一段（面板页脚给了命令），否则包进得来但被 Windows 拦。

## 四、什么时候选它

| 你的情况 | 选它 |
| --- | --- |
| 只有自己和自己的设备（手机 + 电脑 + 平板），想地址固定 | ✅ Tailscale |
| 传的东西敏感，不想经过第三方中转节点 | ✅ Tailscale（直连时是 P2P；DERP 中继也是加密的） |
| 公司网/学校网封了非常规出站，但允许 443 | ✅ Tailscale 走 443 通常能过 |
| 对面那台手机不想装 App、或只是临时借个手机 | ❌ 用公网地址 |
| 想给不熟悉的人发个链接就能下 | ❌ 用公网地址（还得给配对码） |
