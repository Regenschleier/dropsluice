    还没有设备配对。
    手机连不上？先确认两件事：① 手机和电脑在同一个 Wi-Fi；② 防火墙放行了这个端口。
    管理员 PowerShell 里跑一次（端口按需替换）： New-NetFirewallRule -DisplayName "DropSluice" -Direction Inbound -Protocol TCP -LocalPort 18888 -Action Allow -Profile Private,Public -RemoteAddress LocalSubnet
    手机用流量（走 Tailscale）时，还要放行尾网地址那一段： New-NetFirewallRule -DisplayName "DropSluice (Tailscale)" -Direction Inbound -Protocol TCP -LocalPort 18888 -Action Allow -Profile Any -RemoteAddress 100.64.0.0/255.192.0.0
    这个页面只允许在本机打开；关掉电脑上那个黑色窗口就等于停止服务。
